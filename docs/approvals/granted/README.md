# الموافقات الممنوحة

هذا المجلد يكتبه **المالك وحده**. الكتابة فيه ممنوعة على وكلاء Claude في `.claude/settings.json`.

لمنح موافقة: انسخ ملف الطلب من `../requests/` بالاسم نفسه إلى هنا، وأضف في رأسه:

```
status: APPROVED
approved_by: <الاسم>
date: YYYY-MM-DD
scope: <ما تشمله الموافقة بالضبط>
```

موافقة الإصدار يجب أن يحوي اسم ملفها رقم الإصدار (مثل `release-v55.1.md`) لتقرأها بوابة الإصدار.
للرفض: `status: REJECTED` مع السبب. الموافقة لنطاقها فقط ولا تُعمَّم.
