## 1. وصف البنية الحالية

| الطبقة | الواقع |
|---|---|
| الواجهة | React 18 + Vite 6، تطبيق صفحة واحدة عربي RTL/إنجليزي LTR، منشور على GitHub Pages |
| منطق الأعمال المحاسبي | **داخل الواجهة**: `buildAccounting(org, ops)` في `App.jsx` (≈ الأسطر 2160–2870) يولّد دليل الحسابات والقيود من البيانات التشغيلية عند كل عرض؛ يُستدعى من 38 موضعًا |
