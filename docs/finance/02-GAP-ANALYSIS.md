(3) تطابق تام بالهللات في المحرك (A2) خلف مفتاح. (4) اختبارات سلامة مالية: AR/AP Aging = Control، الأصول = الأستاذ، المخزون = الحساب لكل مصدر | موافقة المالك لكل ترحيل بيانات |

## Q. ما يستطيع Claude Code تنفيذه وما يحتاج مختصًا أو جهة خارجية

| يستطيع Claude Code (مع الاختبارات والبوابات) | يحتاج مختصًا محاسبيًا/ضريبيًا | يحتاج جهة خارجية |
|---|---|---|
| تصميم وبرمجة الدفتر المخزّن، المطابقة، تحويل القراءة | الإصدار المطبَّق من IFRS for SMEs والسياسات المحاسبية | تسجيل «فاتورة» واختبار الامتثال (OTP، شهادة الإنتاج) |
| اختبارات السلامة المالية والأداء والأمن | منهجية مخصص الخسائر الائتمانية والهبوط | استضافة سعودية للخادم (اختيار المزود والتعاقد) |
| قائمة الإقفال، تقرير حقوق الملكية، الأبعاد، الموازنات | وعاء الزكاة وضريبة الاستقطاع | مزود OCR إن لم يُستخدم Claude نفسه، واتفاقية معالجة البيانات |
| OCR بنموذج Claude كمقترحات تحتاج اعتمادًا | قواعد التوحيد والأرصدة البينية | البنوك (صيغ الكشوف أو الربط المباشر) |
| الواجهات ولوحة المالية والتقارير | مراجعة القوائم على بيانات حقيقية قبل الاعتماد | مراجع خارجي لاعتماد القوائم |
