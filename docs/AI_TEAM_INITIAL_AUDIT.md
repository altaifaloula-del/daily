## 2. لغات البرمجة والأطر

- JavaScript (ESM)، React 18.3، Vite 6، Node ≥ 22، Express 4.
- Firebase 12 (Auth + Firestore)، `@anthropic-ai/sdk`، `recharts` للرسوم، `lucide-react` للأيقونات، `jsbarcode`.
- الاختبارات: `node --test`، `@firebase/rules-unit-testing` على المحاكي، Playwright 1.63.
- المحرك المحاسبي يُبنى للاختبار في Node عبر `tests/build-engine.mjs` (esbuild) بقائمة تصدير `ENGINE_EXPORTS`.

## 4. قاعدة البيانات والعلاقات

- Firestore بمستندات JSON مجزأة `platform/rms8_*` (البيانات المركزية والفروع)، ومجموعات مستقلة: `fin_docs`، `fin_journal`، `fin_periods`، `closings`، `signoffs`، `audit_log`، `mcp_tokens`، `mcp_proposals`، ومجموعات الحالات والمراجع.
- العلاقات منطقية داخل التطبيق (معرّف الفرع، رمز الحساب، رقم المستند) لا قيود مرجعية في القاعدة.
- لا يوجد Firebase Storage حاليًا.
- مرجع الأمان: `tests/security/CONSTITUTION.md`.

## 5. الوحدات المحاسبية والتجارية

- **المحاسبة:** `buildAccounting` يولّد دليل الحسابات والقيود من العمليات؛ `glLedger`، `acctActivity`، `isLayout` (قائمة الدخل)، الميزان، التدفقات، الموازنة، الأعمار، الإقفال بالفترات (`periodLocked`، `fpLockedTo`)، القيود اليدوية باعتماد (`canApproveJe`)، الأصول والإهلاك (`deprSchedule`)، التسوية البنكية والبطاقات (`parseMt940`، `cardRecon`)، الضريبة (`vatRegister`، `vatCloseLive`).
- **التشغيل:** الإغلاق اليومي والورديات، نقطة البيع والولاء والعروض، المخزون (متوسط مرجّح، دفعات، FEFO، جرد أعمى، إنتاج)، الوصفات والهدر، المشتريات وRFQ، الموارد البشرية والرواتب وGOSI ونهاية الخدمة.
- **التحليل:** لوحة المدير المالي، التحليل المالي المتقدم، الأنماط الشاذة، سجل الحالات الرقابية، التوصيات، التعادل، السيناريوهات، هندسة القائمة.

## 6. الصلاحيات وتعدد المنشآت

- عشرة أدوار في `ROLES`: `cashier`، `branch_manager`، `regional_manager`، `head_office`، `system_admin`، `cost_controller`، `general_management`، `finance_department`، `accountant`، `accountant_view` — لكل دور `scope` (own/assigned/all) و`tabs` و`perms`.
- القواعد تعزل مستندات الفروع حسب الفرع وتشترط MFA للأدوار الحساسة.
- تعدد المنشآت: مشروع Firebase لكل عميل (قرار المالك)، الطيف = المستأجر الافتراضي، منطقة البيانات `me-central2`.
- **مخاطرة معروفة (S1 في خط الأساس v53.9):** توازن القيود وحارس الإقفال يُفرضان في الواجهة على `rms8_core`؛ يجب أن يراعيها وكيل الأمان ووكيل المحاسبة.

## 8. التقارير والطباعة والتصدير

- `printA4` (47 تقريرًا)، و`rptShell` الموحد (ترويسة، ترقيم صفحات، تكرار رأس الجدول)، و`RptTable` (فرز/إخفاء/بحث/عروض محفوظة).
- التصدير: `makeXlsx`/`makeRptXlsx` (Excel بصيغ SUM)، `rptCsv`.
- قرارات المالك: المطبوعات الرسمية بالعربية افتراضيًا مع خيار إنجليزي؛ تحمل شعار المنشأة فقط بلا شعار مِثقال.
- الفجوات الموثّقة: تعميم القالب الموحد على بقية التقارير، كشف حساب لأي حساب، Drill-down موحد.
