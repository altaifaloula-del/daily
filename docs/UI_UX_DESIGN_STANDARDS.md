## 2. المكونات
| المكون | الفئة/المكون | القواعد |
|---|---|---|
| الأزرار | `.btn` + `pri` (أساسي ذهبي) / `gh` (شبحي) / `sm` | زر أساسي واحد لكل منطقة؛ أيقونة 20px + نص |
| الحقول | `.inp`، `.sel`، `Field` | التسمية فوق الحقل؛ رسالة الخطأ تحته بالوردي؛ `inputMode="decimal"` للأرقام |
| الجداول | `.tb`/`.tw`، `RptTable` | الأرقام بـ MizanNum ومحاذاة النهاية؛ السالب بين قوسين وأحمر؛ رأس ثابت؛ فرز/إخفاء/بحث في `RptTable` |
| القوائم | القائمة الجانبية + `HUBS` | أيقونة ثابتة لكل وحدة؛ العنصر النشط بالذهبي |
| النوافذ المنبثقة | `Modal` (`.modal` h/b/f) | عنوان، جسم بتمرير داخلي، أزرار في التذييل (الأساسي في النهاية) |
| البطاقات | `.card` / `.card-t` | ظل خفيف؛ بلا حدود مزدوجة |
| المؤشرات | `Kpi` | العنوان، القيمة، المقارنة، الرابط للمصدر |
| الرسوم البيانية | `recharts` | الترتيب: ذهبي، كحلي، أزرق تقني؛ لا دائري لأكثر من 4 فئات |
| التنبيهات | `.note`، `.hint`، شارات الحالة | نص يشرح ماذا حدث وماذا يفعل المستخدم |
| الحالة الفارغة | `.empty` | جملة إرشاد + إجراء |

### الحالات الموحّدة
hover: حد ذهبي · focus: حلقة ذهبية 2px · disabled: شفافية 0.5 بلا مؤشر · error: حد وردي + رسالة · loading: هيكل رمادي لا دوّار وحيد · success: شارة خضراء مؤقتة.

## 3. RTL وLTR
- `dir="rtl"` للعربية و`ltr` للإنجليزية على مستوى الجذر؛ الترجمة من `i18n-en/` بـ `loadEnPack()`.
- خصائص منطقية فقط: `margin-inline-start`، `padding-inline-end`، `inset-inline-start`، `text-align: start`.
- تنعكس: الأسهم، رجوع/تقدم، أيقونات القوائم المتداخلة. لا تنعكس: الأرقام، الساعات، علامة الصح، الشعارات، الرسوم الزمنية (الزمن من اليسار لليمين في كلا الاتجاهين — قرار يُوثَّق إن غُيِّر).
- النص المختلط (رقم ضريبي، بريد) داخل `<bdi>` أو `dir="ltr"`.
- مقياس التغطية: `node scripts/i18n-coverage.mjs $PWD`.

## 4. Responsive Design
- البدء بالجوال 390px ثم 768 ثم 1440.
- الشبكات `.grid g2–g4` تنهار لعمود.
- الجداول العريضة: تمرير أفقي داخل الحاوية وتثبيت العمود الأول، أو بطاقات على الجوال.
- لا تمرير أفقي للصفحة، ولا قص نصوص.

## 5. الوصولية
WCAG 2.2 AA: تباين 4.5:1 للنص و3:1 للعناصر؛ تركيز ظاهر؛ `aria-label` لأزرار الأيقونات؛ عدم الاعتماد على اللون وحده.
