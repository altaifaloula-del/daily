# معايير التقارير والطباعة والتصدير — MITHQAL ERP

المرجع التنفيذي: `rptShell`، `printA4`، `RptTable`، `makeRptXlsx`، `rptCsv` في `App.jsx`، والكتالوج `PROJECT_AUDIT/ERP_V48/REPORTS_CATALOG.md`.

## 1. المبدأ
**مواصفة واحدة ⇒ ثلاثة مخرجات بأرقام متطابقة**: الشاشة/الطباعة (PDF)، Excel بصيغ حقيقية، CSV.

## 2. القوالب الستة
| القالب | يُستخدم لـ | أمثلة |
|---|---|---|
| قائمة | سجلات متجانسة | سجل الفواتير، الهدر |
| قائمة مالية | أقسام ومجاميع فرعية | قائمة الدخل، المركز المالي، ميزان المراجعة |
| كشف برصيد جارٍ | حركة بأرصدة | دفتر الأستاذ، كشف مورد/عميل/صنف |
| ملخص بمؤشرات | الإدارة العليا | التقرير اليومي للفرع، لوحة المدير المالي |
| مستند بتوقيعات | مطبوعات رسمية | سند، إقفالية، مسير رواتب |
| محوري | مقارنة عرضية | مقارنة الفروع، المبيعات بالساعة |

## 3. فئات التقارير المطلوبة
| الفئة | تقارير رئيسية (تُستكمل من الكتالوج) | القالب |
|---|---|---|
| المالية | ميزان المراجعة، الأستاذ، قائمة الدخل، المركز المالي، التدفقات، الإقرار الضريبي | قائمة مالية / كشف |
| التشغيلية | الإقفال اليومي، الورديات، جرد الصندوق | مستند / ملخص |
| المبيعات والمشتريات | المبيعات حسب الفرع/الطبق/الساعة، مشتريات حسب المورد والتصنيف | قائمة / محوري |
| المخزون | بطاقة صنف، الأرصدة، الاستهلاك النظري/الفعلي، الدوران | كشف / قائمة |
| الموارد البشرية | مسير الرواتب، GOSI، الحضور، الإجازات، نهاية الخدمة | مستند / قائمة |
| المطاعم | تكلفة الأطباق، هندسة القائمة، الهدر، تكلفة الغذاء والعمالة | ملخص / محوري |
| الإدارة العليا | حزمة مجلس الإدارة، بطاقة الأداء، مقارنة الفروع | ملخص |

## 4. الترويسة والتذييل
- **الترويسة:** شعار المنشأة (لا شعار مِثقال — قرار المالك)، الاسم، الرقم الضريبي، العنوان، اسم التقرير، الفترة، التصفية المطبقة، العملة.
- **كل صفحة:** رأس الجدول يتكرر (`thead{display:table-header-group}`)، «صفحة س من ص».
- **التذييل:** المستخدم، وقت الاستخراج، مصدر البيانات (الدفاتر أم الإغلاقات)، «صادر من مِثقال vX» نصًا صغيرًا.

## 5. الأرقام والتنسيق
- خانتان عشريتان، فاصل آلاف، السالب بين قوسين `(1,250.00)`.
- خط الأرقام ثابت العرض ومحاذاة النهاية.
- المجاميع في نهاية الجدول فقط (والمجاميع الفرعية مميزة بالظل الذهبي `#FBF4E4`).
- التقارير المالية تتضمن سطر تحقق («متوازن ✓» أو الفرق).

## 6. الورق والاتجاه واللغة
- A4 (افتراضي) / A3 / Letter؛ طولي أو عرضي؛ هوامش ثابتة.
- الإيصالات الحرارية 58/80mm.
- المطبوعات الرسمية بالعربية افتراضيًا مع خيار نسخة إنجليزية (قرار المالك G1).
- الخطوط محلية من `public/fonts/` — لا اعتماد على الشبكة وقت الطباعة.

## 7. Excel
- ورقة بالاتجاه الصحيح، ترويسة، رأس مجمّد، عرض أعمدة مناسب.
- الأرقام أرقام (لا نصوص)، التنسيق `#,##0.00;(#,##0.00)`، التواريخ تواريخ.
- المجاميع بصيغ `SUM` تغطي صفوف البيانات وحدها، وقيمتها تطابق المجموع المحسوب (اختبار آلي).
- CSV بترميز UTF-8 مع BOM.

## 8. منع القص
- لا عرض ثابت للأعمدة النصية؛ التفاف للنصوص الطويلة.
- عند تجاوز عرض A4 طولي ⇒ عرضي تلقائيًا أو تقسيم أعمدة.
- `tr{break-inside:avoid}`.

## 9. الاختبار الإلزامي
| الاختبار | الأداة | الحالة |
|---|---|---|
| تطابق الأرقام بين الشاشة وExcel وCSV | اختبار آلي (موجود لنموذج G2) | يُعمَّم مع كل تقرير منقول |
| صيغ Excel = المجموع | اختبار آلي | — |
| PDF بلا قص، عربي وإنجليزي، طولي وعرضي | Playwright `page.pdf` + لقطات | يحتاج بيئة Playwright |
| **بيانات حقيقية من بيئة الاختبار** | تشغيل على نسخة اختبار | **لم يُنفَّذ في هذه المهمة** — لا وصول لبيئة اختبار Firebase |
| مطابقة رقم التقرير مع المصدر | `checkSourceVsReport` | متاح |
