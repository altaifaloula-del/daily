# مقترح توحيد أيقونات «مركز التحليل والأداء» — للمراجعة فقط

| البند | القيمة |
|---|---|
| التاريخ | 2026-11-25 |
| الحالة | **مقترح — لم يُنفَّذ.** يحتاج مراجعة `uiux-director` ثم موافقة المالك |
| الملف المتأثر عند التنفيذ | `App.jsx` (`HUBS.analytics`) — تغيير اسم الأيقونة فقط، بلا أثر على البيانات |
| المكتبة | `lucide-react` (موجودة؛ لا اعتماديات جديدة) |

## المشكلة
أيقونة واحدة لعدة معانٍ تجعل المستخدم يعتمد على قراءة النص فقط، وتُضعف التمييز السريع في القائمة.

## المقترح
| الشاشة | الحالية | المقترحة | السبب |
|---|---|---|---|
| المركز نفسه | `Compass` | `Compass` (تبقى) | رمز المركز |
| اللوحة التنفيذية | `Compass` | `Gauge` | لوحة مؤشرات تنفيذية |
| لوحة المدير المالي | `Compass` | `Briefcase` | دور المدير المالي |
| ماذا-لو | `Compass` | `GitBranch` | تفرّع السيناريوهات |
| التحليل المالي المتقدم | `Scale` | `ScanSearch` | تحليل وفحص |
| تحليل التعادل | `Scale` | `Scale` (تبقى) | توازن الإيراد والتكلفة |
| لوحة الأهداف | `CheckCircle2` | `Target` | الأهداف؛ و`CheckCircle2` محجوزة لـ«اعتماد/نجاح» |
| الإجراءات والتوصيات | `CheckCircle2` | `ListChecks` | قائمة إجراءات |
| تحليلات النمو | `TrendingUp` | `TrendingUp` (تبقى) | النمو |
| التوصيات المالية | `TrendingUp` | `Lightbulb` | توصية |
| توقع المبيعات | `TrendingUp` | `LineChart` | منحنى توقع |
| ربحية الفروع اليومية | `TrendingUp` | `Coins` | ربحية |

## التحقق المطلوب قبل الاعتماد
- لقطات القائمة والمركز بالعربية والإنجليزية، جوال وحاسوب، قبل وبعد (`design-quality-auditor`).
- `npm run test:ui` و`tests/hubnav.test.mjs` ناجحة.
- التأكد من وجود كل أيقونة في إصدار `lucide-react` المثبت (0.469) عند البناء.
