# SMART POS GROWTH — تقرير المرحلة E: الولاء المتقدم والكوبونات (v48.1)

## الكوبونات — امتداد لمحرك العروض القائم (لا محرك ثانٍ)
| المتطلب | الحالة | ملاحظة |
|---|---|---|
| نسبة/مبلغ/سعر خاص/اشترِ X واحصل على Y/على الفاتورة/حد أدنى/فروع/وقت/تاريخ/أصناف | PASS (قائم منذ v34) | لم يُغيَّر حسابه |
| رمز فريد، بداية وانتهاء، حد استخدام كلي، لكل عميل، سقف الخصم، استثناء أصناف، لعميل محدد، أول شراء، أعضاء الولاء | PASS | حقول اختيارية؛ العروض القديمة بلا تغيير (اختبار) |
| منع الاسترداد المكرر | PASS | حجز ذرّي بكتابة مشروطة في مستند الولاء المشترك قبل إتمام البيع، بمفتاح عدم تكرار = معرّف الطلب؛ الإلغاء يحرّر |
| بلا اتصال | PASS (احتياطي آمن) | الكوبون المحدود يُرفض برسالة، والبيع يكتمل بدونه |
| التحقق من الخادم | **جزئي** | لا خادم معاملات لنقطة البيع؛ التحقق ذرّي في قاعدة البيانات، لكن العميل الموثوق (حساب موظف) قادر نظريًا على تجاوز الواجهة — موثّق كقيد |
| فحص الهامش قبل التفعيل ومنع الهامش السالب | PASS | من تكلفة الوصفات؛ «غير مكتمل» عند غياب التكلفة |
| الاعتماد فوق حد الخصم | PASS | يُحفظ «بانتظار الاعتماد» ولا يُطبَّق حتى يعتمده من له صلاحية الاعتماد |
| سجل الاسترداد | PASS | شاشة «الكوبونات»: الاستخدام، نسبة الاسترداد، الخصم الممنوح، مبيعات فواتيره (موسومة بأنها ليست إيرادًا إضافيًا)، والسجل |
| ربط الكوبون بالحملة | NOT IMPLEMENTED | المرحلة F |

## الولاء
| المتطلب | الحالة |
|---|---|
| نقاط لكل شراء (قائم) + مضاعف المستوى + مضاعف الفرع + نقاط لكل منتج | PASS — في حساب نقاط نقطة البيع فقط، لا يمس الإجمالي |
| المستويات فضي/ذهبي/بلاتيني بحدود قابلة للضبط (نقاط مشتريات آخر 365 يومًا) | PASS |
| كتالوج الجوائز والاستبدال | PASS — خصم النقاط ثم كوبون شخصي لمرة واحدة ووحدة واحدة؛ إن فشل الإصدار تُعاد النقاط |
| عيد الميلاد والإحالة وانتهاء النقاط | PASS — حركات بمعرّفات حتمية لا تتكرر؛ الإحالة للعملاء الجدد فقط وتُستحق بعد أول شراء |
| دفتر غير قابل للتعديل، العكس عند الإلغاء/المرتجع، التصحيح المعتمد | PASS (قائم + إلحاق فقط) |
| لا مكافأة للملغى/المرتجع كليًا | PASS (قائم: عكس عند الإلغاء وخصم بنسبة المرتجع) |
