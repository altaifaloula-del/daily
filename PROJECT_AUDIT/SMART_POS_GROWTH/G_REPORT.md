# SMART POS GROWTH — تقرير المرحلة G: التوصيات عند الدفع (v52.2)

| المتطلب | الحالة | ملاحظة |
|---|---|---|
| اقتراح أصناف مكمّلة أثناء البيع | PASS | من سلال طلبات الفرع الفعلية (آخر 60 يومًا افتراضيًا): تكرار ≥ 3 طلبات وارتباط ≥ 15% |
| تخصيص حسب العميل | PASS | ما يطلبه عميل الولاء عادةً (مرتان فأكثر)، بالجوال الموحّد |
| لا اقتراح غير متاح/مكرر | PASS | الموقوف من نقطة البيع، وما في السلة، وما أخفاه الكاشير — مستبعد |
| لا أثر مالي | PASS | الاقتراح يضيف الصنف بسعره العادي؛ العروض والضريبة كما هي (اختبار: الإجمالي 53) |
| تسجيل العرض/القبول/الإخفاء | PASS — بتصميم معدّل | داخل الفاتورة: `recShown` و`recDismissed` و`line.rec` — بدل مجموعة `mktRecEvents` المخططة، لتجنّب كتابة لكل عرض وتضخيم مستند الفرع (BUG-00-11)؛ وتعمل دون اتصال مع الفاتورة |
| تقرير الأداء | PASS | «التسويق والنمو ← التوصيات»: العرض، القبول ونسبته، الإخفاء، مبيعات الأسطر المقبولة (موسومة بأنها ليست إيرادًا إضافيًا بالضرورة)، لكل صنف وفرع وفترة |
| الإعدادات والصلاحية | PASS | `org.mkt.recs`: تشغيل/إيقاف، الفترة، الحدود، العدد — لمن له صلاحية الاعتماد، مع سجل تدقيق |
| ذكاء اصطناعي | خارج النطاق | قواعد إحصائية شفافة؛ المساعد الذكي في المرحلة J |

## الاختبارات
- المحرك: 4 جديدة (الإعداد، «يُطلب معه» بالحدود والاستبعادات والفرع والفترة، المعتاد للعميل، النتائج).
- الواجهة: v52.2 (الاقتراح والإضافة والإخفاء والحفظ في الفاتورة، والنتائج والإعدادات في التسويق).
