# SMART POS GROWTH — تقرير المرحلتين C وD (v48.0)

## ما بُني
| المتطلب | الحالة | الإثبات |
|---|---|---|
| مركز «التسويق والنمو الذكي» بتبويب صلاحية `mkt` ضمن نظام الأدوار القائم | PASS | الدور: الإدارة/المكتب الرئيسي/المدير الإقليمي/مدير الفرع؛ اختبار «الدستور» يطابق قواعد Firestore |
| صلاحية الاعتماد من الأدوار القائمة (`admin`/`approver`) لا نظام ثانٍ | PASS | `mktCanApprove` — اختبار محرك |
| لوحة التسويق: المبيعات، متوسط الفاتورة، النشطون/الجدد/العائدون، الاحتفاظ، غير النشطين، VIP، الموافقون، مقارنة الفروع، فلاتر التاريخ والفرع | PASS | من `posOrders` الفعلية؛ اختبار محرك + واجهة |
| مؤشرات الحملات/الكوبونات/العائد/الربح الإضافي | NOT IMPLEMENTED (مراحل E–H) | تُعرض «تُفعَّل في مرحلة لاحقة» — لا أرقام مختلقة (اختبار يتحقق أنها null) |
| ملف العميل: الهوية بالجوال، الاسم، أول ظهور، آخر شراء، الزيارات، الإجمالي، المرتجع، المتوسط، الفروع المفضلة، الأكثر شراءً، الدورية، النقاط، الموافقة، ربط عميل B2B | PASS | `crmBuild` |
| البريد/الكوبونات النشطة/تاريخ الحملات في الملف | NOT IMPLEMENTED | البريد غير مُجمَّع في نقطة البيع؛ الباقي مع المراحل E–F |
| الشرائح الست بقواعد قابلة للضبط + «عاديون» | PASS | `crmSegment` + شاشة الإعدادات |
| كشف التكرار بلا دمج تلقائي، ودمج معتمد بسبب مكتوب ونقل النقاط بحركة دفتر | PASS | `crmDupes`، `mktMerges`، `loyPost` |
| سجل الموافقة/إلغاء الاشتراك غير القابل للتعديل لكل قناة | PASS | `mktConsents` إلحاق فقط؛ `mktCanContact` |
| التصدير للموافقين فقط | PASS | تصدير الشرائح |
| عزل الفروع | PASS | مدير الفرع يرى عملاء طلبات فرعه فقط (اختبار واجهة) |
| عربي/إنجليزي، جوال/لوحي/مكتب | PASS (عربي، وجولة كل الشاشات بلا تجاوز عرض الجوال) | الواجهة الإنجليزية عبر `TX` تحتاج ترجمات النصوص الجديدة — **جزئي** |

## الانحدار
- اختبارات المحرك: 138/138 (منها 5 جديدة).
- الواجهة: كل الاختبارات نجحت، بما فيها جولة كل الشاشات واختباران جديدان؛ ما عدا v44.5 محليًا فقط (مكتبة الباركود بديلة دون شبكة — تنجح على GitHub).
- لا تغيير على: `posTotals`، الضريبة، القيود، إجماليات الفواتير، محرك العروض، دفتر الولاء القائم (إلحاق فقط).

## قيود معروفة
- التحليل يغطي الطلبات المعرَّفة بجوال العميل فقط؛ نسبة التعريف تظهر في اللوحة.
- المجموعات الجديدة في المستند المركزي؛ عند نمو كبير جدًا لعدد الموافقات يُنقل للتجزئة (المراحل اللاحقة).
