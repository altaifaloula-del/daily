# MIGRATION PLAN — حماية وترحيل البيانات

## مبادئ ثابتة
1. لا ترحيل مدمر. كل ترحيل: نسخة احتياطية مشفرة مُتحقق منها ← تشغيل جاف (dry-run) يعرض الفروقات ← موافقة المالك ← تنفيذ قابل للعكس.
2. لا تغيير لأسماء الحقول أو مفاتيح التخزين (`platform/*`، `rms8:*`) دون طبقة توافق تقرأ الشكلين.
3. الميزات الجديدة معطلة افتراضيًا مع توافق رجعي.

## الدفعة 1
لا ترحيل بيانات. التغييرات في الإعدادات والتوثيق فقط.

## مخطط مبدئي (يحتاج موافقة قبل التنفيذ)
- **المرحلة 2:** تقييم الانتقال من «مستند كبير مقسّم» إلى مجموعات على مستوى السجل (قيود، حركات مخزون، فواتير) — على مراحل، بالقراءة المزدوجة أولًا، ثم الكتابة المزدوجة، ثم التحويل. لن يبدأ دون موافقة صريحة لأنه يمس بنية البيانات الفعلية.
