# REPORTING SYSTEM — v56.0

## المحرك (قائم — لم يُنشأ محرك موازٍ)
مواصفة واحدة `spec` → ثلاث مخرجات من البيانات نفسها:
- **الشاشة:** `RptTable` (فرز، قوالب، تصدير)
- **PDF/طباعة:** `rptHtml` (ترويسة المنشأة، رأس جدول يتكرر في كل صفحة، `tr{break-inside:avoid}`، ترقيم «صفحة X من Y»، تذييل بالطابع والوقت والمصدر، A4/A3/Letter عمودي/أفقي)
- **Excel:** `rptXlsxRows/makeRptXlsx` (رأس مجمّد، تنسيق أرقام، صيغ `SUM` حقيقية) · **CSV:** `rptCsv` (UTF-8 مع BOM، قيم خام)
والإجماليات كلها من `rptTotals` نفسها ⇒ أرقام الشاشة = PDF = Excel (اختبار `branding.test` #5 و`v56.test` «التقارير تطابق الدفتر»).

التصميم منفصل عن المنطق: القالب يغيّر العرض فقط؛ الحسابات في المحرك المحاسبي ولم تُمس.

## القوالب الستة (بمعرّفاتها القائمة منذ v50؛ أسماء الأمر بدائل مقبولة)
| أمر التصميم | المعرّف | العرض |
|---|---|---|
| List | `list` | جدول مع مجموعات ومجاميع فرعية |
| Financial | `statement` (`financial`) | مستويات بإزاحة، عناوين أقسام، خط إجمالي مزدوج، بلا حدود عمودية |
| Statement | `ledger` | سطر رصيد افتتاحي وختامي (`spec.opening/closing`) |
| Summary | `summary` | مؤشرات بارزة مع اتجاه ▲/▼ (`kpis[].delta`) ثم جدول |
| Official Document | `document` (`official`) | ترويسة متمركزة، أعدّه/اعتمده، موضع الختم |
| Pivot | `matrix` (`pivot`) | `rptPivot`: مجموع قيمة لكل صف×عمود + إجماليات (عرض فقط). **تفاعلي على الشاشة** في `RptTable` (زر «تبديل الصفوف والأعمدة») بالدالة نفسها، فالشاشة = الطباعة = Excel = CSV. لا يوجد بعد تقرير قائم يعرّف مواصفة محورية — المكوّن جاهز |
