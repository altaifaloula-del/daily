# SCREEN MIGRATION — v56.0

## المنهج
كل الشاشات (≈131 ملفًا في `mods/` + الشاشات في `App.jsx`) تُرسم بالفئات والمتغيرات المشتركة، فأي تحديث للرموز يصل إليها كلها. لم تُعَد كتابة أي شاشة مستقرة. التحقق الشامل: اختبار «كل الشاشات» يفتح **كل مسار** (`window.routes`: كل المراكز، كل أقسام المحاسبة، والتطبيقات المستقلة) على الجوال والحاسوب، ويفشل عند أي انهيار أو خطأ تشغيل أو تجاوز لعرض الجوال أو أرقام هندية.

## ما تغيّر فعليًا في v56
| الموضع | التغيير |
|---|---|
| `BrandSymbol` (كل مواضع شعار المنصة: القائمة، الشريط، الدخول، أيقونة التطبيق) | الرمز الهندسي الجديد من `brand-geom.js` |
| `public/icon.svg`, `favicon.ico`, PNG الأيقونات، `public/brand/*` | مولّدة من الحزمة الجديدة |
| الشريط العلوي | `TenantChip` لهوية المنشأة؛ عنوان الرئيسية «الرئيسية» بدل اسم المنشأة (الاسم صار في موضعه المخصص) |
| القائمة الجانبية | اسم/شعار المنشأة من `tenantBrand` (البديل للخلفية الكحلية) |
| شاشة الدخول | شعار المنشأة من المحلّل المعقّم؛ **إصلاح الوضع الداكن** (DESIGN-V56-001) |
| الإعدادات ← بيانات الشركة | بطاقة «الهوية التجارية للمنشأة» الجديدة |
| كل المستندات المطبوعة (16 قالبًا) | ألوان المنشأة بدل كحلي المنصة، وشعار المستندات المعقّم — `REPORTS_MIGRATION_V56.md` |
| `exportExcel` (تصدير HTML لـ Excel) | ألوان محايدة بدل ذهبي/كحلي المنصة |

## الدفعة الثانية (البنود المتبقية)
| الموضع | التغيير |
|---|---|
| الرئيسية | لوحات الأدوار التسع تحت أرقام اليوم |
| الشريط العلوي | زر البحث العام (Ctrl/⌘+K)، شارة المنشأة صارت محدد منشأة، مستمع الاختصارات |
| شريط أقسام كل المراكز (الجوال) | سطر واحد قابل للتمرير بدل ~5 أسطر (DESIGN-V56-008)، ومبدّل العرض أيقونات (010) |
| ملخص المحاسبة (الجوال) | شبكة 2×2 مضغوطة (009) |
| النص الذهبي في 45 موضعًا (11 شاشة جداول) | رمز `--brass-t` آمن للنص في الفاتح (013) |
| نموذج الفرع | لون مستندات الفرع |
| الفاتورة | ثلاثة قوالب |
