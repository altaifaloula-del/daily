## 3. القدرات الناقصة
- تتبّع كل رقم: المعادلة + الحسابات المصدرية + الفترة + المقارنة + المخاطرة + الإجراء.
- فحص «اكتمال البيانات» قبل حساب أي نسبة (لا مبيعات/لا نقدية/لا أرصدة افتتاحية ⇒ النسبة تُرفض مع السبب).
- نسب: السريعة، النقدية، الدوران (مخزون/عملاء/موردين)، العائد على الأصول وحقوق الملكية، التدفق التشغيلي.
- مكتبة مراجع بإصدارات وتواريخ نفاذ واستشهاد بالصفحة؛ OCR؛ بحث.
- سجل حالات أخطاء دائم بدورة حياة وإعادة تحقق وإعادة فتح (التنبيهات الحالية لحظية).
- فحوص محاسبية حتمية: فواتير مكررة، أرصدة بعكس طبيعتها، ضريبة غير مطابقة، تصنيف مشكوك فيه.
- درجات صحة مالية بمنهجية مكتوبة وتنقيب حتى القيد.
- سجل طلبات الذكاء الاصطناعي.
