# Invented global brand names from Arabic roots: vetting for a Saudi cloud ERP (Nov 2026)

Scope: 37 coined candidates built from Arabic roots meaning all / total / gathered / complete / one (ك ل ، ج م ع ، ج م ل ، ش م ل ، ك م ل ، و ح د ، ل م م ، ض م). Each was checked by web search (Apple App Store, Google Play, Capterra/G2/GetApp, Crunchbase, Clutch, general web). Searches were run on 2026-11-25.

**Method caveats (read first):**
- The search engine handled `OR` queries loosely. So the 11 kept names each got at least one exact-match query on the bare name, plus one or more product-context queries ("app / software / ERP / fintech / company").
- I could not do domain (WHOIS/RDAP/DNS) lookups. The session's network proxy blocked direct DNS, DNS-over-HTTPS and `rdap.verisign.com` (error: "no rule or network setting allows this host"). The ".com status" below therefore only says whether a live site showed up in web search. It is **not** a registration check.
- The language checks (negative meanings in Arabic/English/Urdu/Turkish/French/Spanish/Italian) are my own analysis unless a source is cited. A native-speaker panel should confirm them.

## Q1. Which coined names survive the software/fintech conflict search? (KEEP list, ranked)

### Takeaway
11 names showed no software, app or fintech use under the exact spelling: **Majmo, Tajmo, Jamlen, Lamena, Kamlen, Kollana, Wahido, Jamelo, Tamlen, Lamaro, Wahena**. The strongest on meaning, ease of pronunciation and cleanliness are **Majmo** (مجموع "total"), **Tajmo** (تجمّع "gathering") and **Jamlen** (جملة "total / sum").

### Cited Findings

**1. Majmo — مَجمو**
- Formation: truncation of مَجموع *majmūʿ* ("total, sum, aggregate"). The final ع is dropped so English speakers get no glottal or pharyngeal sound. To an Arabic ear it reads as "the total", which suits an accounting system (المجموع at the bottom of every report).
- Pronunciation: MAJ-mo. Two syllables, five letters. The sounds are identical for Arabic and English speakers, with no P, V, th, q or hamza.
- Exact-name search: no product, company or app called "Majmo". The nearest hits were MaYoMo (a defunct citizen-journalism site), Majo Games and GitHub user "Majimo" — [search results incl. MaYoMo](https://Www.Wikipedia.org/wiki/MaYoMo), [Majimo GitHub](https://github.com/Majimo).
- Context search ("Majmo app/software/ERP"): no match — [Capterra Zeymo (unrelated, returned in same query)](https://www.capterra.com/p/10006059/Zeymo/).
- **Risk to note:** **majoo** (PT Majoo Teknologi Indonesia) is an Indonesian POS/business app that also sells an ERP. It is a different spelling, but it is in the same product category and looks alike in print (majoo vs majmo) — [majoo ERP](https://majoo.id/custom/erp-solution), [majoo App Store](https://apps.apple.com/app/id1642259472). The variants "Majmoo/Majmou" also returned only majoo.
- .com: no live majmo.com site appeared in search. Registration is unverified.

**2. Tajmo — تَجمو**
- Formation: from تَجَمُّع *tajammuʿ* ("gathering, coming together"), root ج م ع, with the final ع dropped. Persian/Urdu speakers also hear *Taj* ("crown").
- Pronunciation: TAJ-mo. Two syllables, five letters, read the same by both groups.
- Exact-name search: no company or product. The only near hits were a Tsotsil dictionary word "tajmoj", the PyPI package "tajm2" and a DJ "tajm" — [Tsotsil entry](https://livingdictionaries.app/batsi-kop-tsotsil-tsot/entry/qVeS5kz3A1Uv2KY1xzAn), [tajm2 PyPI](https://pypi.org/project/tajm2/0.0.5).
- "Tajmo ERP/fintech/company": none. The nearest was Taja, an African cross-border payments company (different name) — [results page incl. Taja](https://businessday.ng/?p=1207772).
- .com: no tajmo.com site appeared in search, including in a targeted ".com" query.

**3. Jamlen — جَملن**
- Formation: root ج م ل as in جُملة *jumla* ("total, sum; wholesale" — بالجملة), with the soft ending -en. To an Arabic ear it suggests "in total" or "wholesale".
- Pronunciation: JAM-len. Two syllables, six letters.
- Exact-name search: only a GitHub user "jamlen" (Manchester) with forked repos. No product — [github.com/jamlen](https://github.com/jamlen).
- Context search (with Jamilo/Jameo): no Jamlen product — [AppBrain Jamilo dev (different name)](https://www.appbrain.com/dev/Jamilo/).
- .com: none seen.

**4. Lamena — لَمّينا**
- Formation: root ل م م *lamm* ("to gather, bring together"). In Gulf and Levantine dialect لمّينا *lammēna* means "we gathered (it) up", and لمّة means a get-together.
- Pronunciation: la-MEE-na. Three syllables, six letters.
- Exact-name search: only a Bugis name for a mail-and-plate armour vest ("baju lamina", also called "lamena") and the Lamen Bay language — [Baju Lamina, Wikipedia](https://en.wikipedia.org/wiki/Baju_Lamina).
- App search: no product. Nearby names are taken: **Lamenu** (restaurant QR menu app) and **Lamma** (event app, e-wallet, Bahrain ordering app, Tunis delivery) — [Lamenu](https://apps.apple.com/cz/app/lamenu/id1500768465?l=cs), [Lamma Product Hunt](https://www.producthunt.com/products/lamma/reviews), [Lamma Bahrain app](https://apps.apple.com/us/app/lamma-app/id1605119039).
- .com: none seen.

**5. Kamlen — كاملن**
- Formation: root ك م ل *kāmil* ("complete") plus -en. In Gulf dialect كاملين *kāmlīn* means "complete (pl.) / all of them".
- Pronunciation: KAM-len. Two syllables, six letters.
- Exact-name search: only Kamlen, a non-player character in the Elder Scrolls mod *Tamriel Rebuilt* — [UESP Tamriel Rebuilt:Kamlen](https://en.uesp.net/wiki/Tamriel_Rebuilt:Kamlen).
- Software/app search: none. Nearby names are Camlenio Software (Jaipur dev shop) and the "Kamli" app — [Camlenio](https://froont.com/camlenio-software/best-software-company-in-jaipur/-info), [Kamli](https://play.google.com/store/apps/details?id=com.theAppkit).
- .com: none seen. kamlo.com, a near-variant, appears parked at Afternic — [whoxy kamlo.com](https://www.whoxy.com/kamlo.com).

**6. Kollana — كُلّنا**
- Formation: كُلُّنا *kullunā* ("all of us"). This is the strongest "all / unified" signal, but it is a real Arabic phrase (pronoun + suffix), not a dictionary headword. Transliteration may drift (Kullana / Kolana).
- Pronunciation: kol-LA-na. Three syllables, seven letters.
- Exact-name search: no product. Hits were Kollannur (a Kerala family name), the Kolata dance and the Kolla people — [Kollannur](https://en.wikipedia.org/wiki/Kollannur).
- App search: no Kollana. The "Koll-" space is crowded: **Kolleno** (AR-automation software for finance teams — the closest conflict), Kollo (workplace app), Kolla (integration platform), KolApp — [Kolleno App Store](https://apps.apple.com/vg/app/kolleno/id1673036492), [Kolleno Crunchbase](https://www.crunchbase.com/organization/kolleno), [Kollo](https://apps.apple.com/in/app/kollo/id6737515863), [KolApp Capterra](https://www.capterra.com/p/10017799/KolApp/).
- .com: none seen.

**7. Wahido — واحدو**
- Formation: واحد *wāḥid* ("one / unified") plus -o.
- Pronunciation: wa-HEE-do. English "h" replaces ح, which is acceptable.
- Exact-name search: only the Japanese romanisation "Wahīdo" of a character in the anime *Magi*, plus Wahid / Wahida name pages — [Magi wiki Wahid](https://magi.fandom.com/wiki/Wahid).
- App search: no Wahido. Related names are taken: **Wahdapp** (prayer app) and **WAHDAH** (travel app) — [Wahdapp, The New Arab](https://www.newarab.com/news/taiwanese-student-turkey-develops-muslim-prayer-app), [WAHDAH App Store](https://apps.apple.com/mx/app/wahdah/id6504530804).
- **Caveat (own analysis):** al-Wāḥid is one of the 99 Names of God. Some Saudi and GCC customers may find a trademark built on it sensitive, so check with SAIP before using it.

**8. Jamelo — جَميلو / جُملو**
- Formation: ج م ل (jumla = total, or jamīl = beautiful) plus -o.
- Exact-name search: results were dominated by Jamelão, the Brazilian samba singer. No product — [Jamelão, Wikipedia](https://wikipedia.com/wiki/Jamel%C3%A3o).
- Fintech search: no match. Nearby names are Jamiipay and Jamii.one (savings-group apps) and Djamo (fintech) — [Jamiipay](https://apps.apple.com/sg/app/jamiipay/id1471553964), [Djamo](https://apps.apple.com/us/app/djamo/id1504072402).

**9. Tamlen — تَملن**
- Formation: loosely from ت م م (*tamām*, "complete") with -len. The Arabic link is weaker, and Tamam is on the exclusion list, so this may count as a close variant.
- Exact-name search: no product. Near hits were the Tammen surname and Tammelinn (Tartu) — [Tammen](https://en.wikipedia.org/wiki/Tammen), [Tammelinn](https://en.wikipedia.org/wiki/Tammelinn).

**10. Lamaro — لَمّارو**
- Formation: ل م م ("gather") plus -aro.
- Exact-name search: Michele Lamaro (Italy rugby captain), the music artist LAMARO and a racehorse. No software — [Michele Lamaro](https://cavac.at/cavacopedia/Michele%20Lamaro), [LAMARO last.fm](https://www.last.fm/music/LAMARO/+events).
- Caveat (own analysis): Italian *l'amaro* = "the bitter (one)".

**11. Wahena — واحِنا**
- Formation: from و ح د plus -ena. The Arabic link is weak.
- Exact-name search: no product, only Hawaiian *wehena* ("opening; solution") and Māori *whena* — [Wehewehe dictionary](https://wehe.colo.hawaii.edu/?q=wehena), [pantheon.org Whena](https://pantheon.org/articles/w/whena.html).

### Inferences
- Best three for this brief: **Majmo** (clearest "total" meaning for accounting; only risk is majoo's look-alike), **Tajmo** (cleanest overall: no conflicts and easy for every audience) and **Jamlen** (clean; جملة = total / wholesale suits POS and inventory).
- Second tier: **Lamena** (warm Gulf "lamma" feeling, but sits next to the crowded Lamma/Lamenu names), **Kamlen** (Urdu/Hindi *kam* = "less / few" might be noticed by South-Asian staff in GCC; English speakers may hear "camel"), **Kollana** (strongest meaning, but transliteration drift and the nearby Kolleno finance software are real risks).
- Lower tier: Wahido (religious sensitivity), Jamelo, Tamlen (close to the excluded Tamam), Lamaro (Italian "bitter"), Wahena (weak root link).
- Language screen (own analysis, needs native confirmation):
  - Majmo, Tajmo, Jamlen: no known negative meaning in Arabic, English, Urdu, Turkish, French or Spanish.
  - Lamena: Spanish *la mena* = "ore", which is neutral.
  - Jamelo: Spanish *jamelgo* = "nag (horse)" is a distant echo.

### Gaps
- **.com availability was not verified for any name.** WHOIS/RDAP/DNS hosts were blocked by the session proxy. To check, allow `rdap.verisign.com` in the session's network settings or check manually at a registrar.
- Trademark databases (SAIP Saudi Arabia, GCC TM, WIPO Global Brand Database, USPTO, EUIPO) were not searched.
- Each kept name got about 2–3 queries, not the full five-variant sweep (name + app / software / ERP / fintech / company, plus close spellings), because of the tool-call budget. Before shortlisting, run the full sweep on the top 3.
- I could not find any source for the claimed Dragon Age character "Tamlen", so it is not asserted here.

## Q2. Which candidates were rejected, and why?

### Takeaway
26 of 37 candidates were rejected. Fourteen had a direct software, app or fintech conflict, or malware. The others were rejected for a negative or awkward meaning, a dictionary word, a well-known place or brand collision, or being too close to an excluded name.

### Cited Findings
**Rejected for software/app/fintech conflict**
- **Jamio** — Jamio openwork, a no-code BPM/business-process platform by openwork srl (Italy), plus a Jamio music app — [App Store Jamio openwork](https://apps.apple.com/app/id606202857), [krowdbase](https://www.krowdbase.com/software/jamio-openwork), [Jamio music app](https://apps.apple.com/us/app/jamio/id6746352092).
- **Shamla** — Shamla Tech Solutions (Coimbatore), a software/Web3/fintech development firm with 100–249 staff. It is also a close variant of the excluded Shamel/Shumoul — [GoodFirms](https://www.goodfirms.co/company/shamla-tech-solutions), [DesignRush](https://www.designrush.com/agency/profile/shamla-tech-solutions).
- **Shamlo** — too close to the excluded Shamel (Shamel App / ShamelPro business app by Al Obeikan). It is also the name of the famous Iranian poet Ahmad Shamlou / Shamlu tribe — [ShamelPro](https://apps.apple.com/sg/app/shamelpro/id1641501416), [Ahmad Shamlu](https://wikipedia.com/wiki/Ahmad_Shamlu).
- **Shamio** — Shameo voice-assistant app (sounds identical). English speakers also hear "shame" — [Shameo App Store](https://apps.apple.com/gy/app/shameo/id6502933620).
- **Shamena** — "shame" sound in English; the Shamna app; a variant of Shamel — [Shamna](https://sourceforge.net/app/shamna/android/).
- **Damio** — a feedback-management SaaS — [AlternativeTo Damio](https://alternativeto.net/software/damio/about/), [BetaList Damio](https://betalist.com/startups/damio).
- **Lumma** (لُمّة "get-together") — Lumma Stealer, a widely reported info-stealing malware (MITRE S1213; disrupted May 2025, later re-emerged) — [MITRE ATT&CK](https://attack.mitre.org/software/S1213), [Wikipedia](https://en.wikipedia.org/wiki/Lumma_Stealer), [Microsoft Security](https://microsoft.com/en-us/security/blog/2025/05/21/lumma-stealer-breaking-down-the-delivery-techniques-and-capabilities-of-a-prolific-infostealer).
- **Lamma / Lammo** — multiple Lamma apps: Bahrain ordering, an e-wallet, an event app, and Tunis/North-Africa delivery (Flat6Labs) — [Product Hunt](https://www.producthunt.com/products/lamma/reviews), [Lamma Bahrain](https://apps.apple.com/us/app/lamma-app/id1605119039), [Crunchbase LAMMA](https://www.crunchbase.com/organization/lamma-b457), [Flat6Labs](https://www.flat6labs.com/Company/lamma/). "Lammo" also sits next to the Lamo apps — [Lamo](https://iphoneaddict.fr/apps/style-de-vie/lamo-482.html).
- **Lamna** — a LamnAI startup exists. It is also a shark genus — [LinkedIn post](https://cy.linkedin.com/in/alexnikita).
- **Kollena** — sounds almost the same as **Kolleno**, accounts-receivable automation software for finance teams — [Kolleno](https://www.crunchbase.com/organization/kolleno).
- **Kamlo** — sounds the same as **Qamlo**, a software / integration-services firm (qamlo.com). kamlo.com is parked — [village.ai Qamlo](https://village.ai/company/qamlo), [whoxy kamlo.com](https://www.whoxy.com/kamlo.com).
- **Kamla** — the Kamali loan app (Home Credit, Czechia) is close; Kamla is also a common Hindi female name — [Kamali App Store](https://apps.apple.com/cz/app/id1225328408).
- **Wahdo / Wahden** — Wahdapp (prayer app, "unity") and the WAHDAH travel app — [The New Arab](https://www.newarab.com/news/taiwanese-student-turkey-develops-muslim-prayer-app), [WAHDAH](https://apps.apple.com/mx/app/wahdah/id6504530804).
- **Kamena** — kamena.com is the website of Kamena Products Corporation, an Egyptian flavours/fragrances company (est. 1976; Egypt/UK/USA). It is not software, but the .com is taken and it is MENA-visible — [PotatoPro profile](https://www.potatopro.com/zh-hans/companies/kamena-products-corporation).

**Rejected for meaning or collision (own linguistic analysis unless cited)**
- **Jomla / Jumlo** — reads as or sounds like **Joomla** (CMS with many ERP extensions); "Jumlo" also sounds like "jumbo" — [Joomla Easy ERP](https://extensions.joomla.org/extension/easy-erp).
- **Jamaro** — Arabic ear hears جمر / الجمرات (embers / Hajj stoning pillars). It is also close to Urdu/Hindi *Jamoora*, a pejorative "puppet / sidekick" — [Jamoora, Wikipedia](https://wikipedia.com/wiki/Jamoora). The Jamora app is nearby — [Jamora](https://apps.apple.com/us/app/jamora/id6444741888).
- **Kulna** — sounds like Khulna (Bangladesh city). Kula apps exist — [Kula](https://startup-seeker.com/company/kula~app).
- **Jamna** — the Hindi/Urdu form of the Yamuna river name; weak (unsourced; own analysis).
- **Kamina** — Hindi/Urdu कमीना *kamīnā* = "scoundrel"; a strong insult for South-Asian GCC staff (own analysis).
- **Kulo / any Kul- start in Turkish** — Spanish/Italian *culo* = "arse"; Turkish *kul* = "slave / servant" (own analysis).
- **Kulli** — sounds like "coolie" (a derogatory term in South Asia / East Africa) (own analysis).
- **Kulan** — the English name of the Asian wild ass (own analysis).
- **Kamelo / Kamaro** — "camel" / Chevrolet Camaro (own analysis).
- **Lamina** — an English dictionary word (own analysis).
- **Dammen / Damma** — English "damn"; Damen shipyards; ضمّة is a vowel mark — [Damen LFE app](https://apps.apple.com/ca/app/damen-lfe/id1165415900).
- **Jamilo / Jameo** — Jamilo is a Google Play developer name; Jameo / Jameia family-group app; Jamila is a common given name — [AppBrain Jamilo](https://www.appbrain.com/dev/Jamilo/), [Jameia](https://apps.apple.com/se/app/jameia/id1464149561).
- **Kamalo / Kamaly / Jamaly** — read as surnames; Kamal Tech Labs exists — [GoodFirms Kamal Tech Labs](https://www.goodfirms.co/company/kamal-tech-labs).
- **Jamen** — no conflict found, but it is weak: "ja men" ≈ Scandinavian "yes but", and Yamen ≈ Yemen (own analysis).
- **Wahoda / Ahaden / Dammala** — no conflicts, but they are awkward: three to four syllables, ح/ض clusters, and Dammala ≈ English "dammle" (own analysis). Searched — [results incl. WAHDAH, DamaMall](https://apps.apple.com/iq/app/damamall/id6502008448).

### Inferences
- The ل م م ("gather") root is heavily used in GCC consumer apps (Lamma × 4+), and the "Koll-/Kull-" space is crowded in software (Kolleno, Kollo, Kolla, KolApp). Coinages from ج م ع / ج م ل and from مجموع have more open room.
- Every name that starts with "Kul-" carries Turkish *kul* = "slave". This matters if Turkey is a target market.

### Gaps
- The rejection notes for Kamina, Kulli, Kulo, Kulan and Jamna come from my own linguistic knowledge and were not confirmed by a web source in this pass.
- Jamen, Wahoda, Ahaden and Dammala had no conflicts found. They were rejected on quality, not on conflicts.

## Q3. Is the .com in active use for the kept names?

### Takeaway
No live website came up in web search for majmo.com, tajmo.com, jamlen.com, lamena.com, kamlen.com, kollana.com, wahido.com, jamelo.com, tamlen.com, lamaro.com or wahena.com. Registration status is unknown because domain-lookup hosts were blocked.

### Cited Findings
- A targeted query for "kamlen.com / tajmo.com / tamlen.com / jamaro.com" returned no page on those domains. The only near-match was kamlo.com, which is registered via Uniregistry with Afternic nameservers, i.e. parked or for sale — [whoxy kamlo.com](https://www.whoxy.com/kamlo.com).
- kamena.com is in active use (Egyptian flavours company) — [PotatoPro](https://www.potatopro.com/zh-hans/companies/kamena-products-corporation).

### Inferences
- Short five-letter .com names (majmo, tajmo) are often registered, parked or held by domainers even when no site shows up in search. Assume a buy-from-reseller cost is possible.

### Gaps
- Direct HTTP, DNS and RDAP checks failed with "agent proxy: no rule or network setting allows this host" for every domain tested, so registration and active use were not confirmed. Recommended next step: allow `rdap.verisign.com`, or check manually at a registrar.
